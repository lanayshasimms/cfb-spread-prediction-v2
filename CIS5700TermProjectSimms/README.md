# College Football Spread Forecasting

This project evaluates deep-learning models for predicting the point spread of college football games from recent team statistics. It compares three sequence-modeling approaches:

- **DLinear**, which decomposes each input sequence into trend and remainder components before applying linear layers.
- **LSTM**, which models temporal relationships with a recurrent neural network.
- **Transformer**, which uses self-attention and learned positional encodings.

The models use the previous 3, 4, or 5 games for each team and predict the spread of the next game. Performance is reported with mean squared error (MSE) and mean absolute error (MAE).

## Dataset and preprocessing

The input dataset is `Feature_Reduced_Set.csv`. `data_prep.py`:

1. Removes the `home_win` and `neutral` columns.
2. Sorts games chronologically by season and week.
3. Extracts the team and year from the `home_season` column.
4. Splits the data chronologically:
   - Training: seasons through 2022
   - Validation: 2023
   - Test: 2024
5. Converts the selected features to numeric values and drops rows with missing values.
6. Builds separate sequences for each team so a sequence never crosses from one team to another.

The target variable is `spread`. The input features include week, team rankings, quarter scoring, first downs, fumbles, interceptions, penalties, time of possession, third-down completion rate, pass completion rate, run-pass ratio, and rushing share of total yards.

## Project files

| File | Purpose |
| --- | --- |
| `data_prep.py` | Loads the CSV, creates chronological splits, defines features, and builds sequences. |
| `dlinear.py` | Defines and trains the DLinear model, evaluates it, and runs DLinear regularization tuning. |
| `lstm.py` | Defines and trains the LSTM model, evaluates it, and runs LSTM regularization tuning. |
| `transformer.py` | Defines and trains the Transformer model, evaluates it, and runs Transformer regularization tuning. |
| `summary_table.py` | Prints the best configurations overall and for each window size. |
| `error_v_window.py` | Plots the best MSE for each model and window size. |
| `*_results.json` | Baseline experiment results. |
| `*_reg_results.json` | Regularization and hyperparameter-tuning results. |
| `best_*_w*.pt` | Saved model weights selected by validation loss. |
| `error_vs_window.png` | Generated plot of MSE versus input window size. |

## Setup

Use Python 3. Install the project dependencies with:

```bash
pip install numpy pandas matplotlib torch
```

Run commands from the directory containing the Python files and `Feature_Reduced_Set.csv`, because the scripts use relative file paths.

## Running the experiments

To train and evaluate a model, run its script:

```bash
python dlinear.py
python lstm.py
python transformer.py
```

Each script trains baseline models for window sizes 3, 4, and 5, saves the best checkpoint for each window, evaluates on the 2024 test split, and writes baseline results to a JSON file.

Each script then performs a regularization and hyperparameter sweep over:

- Window sizes: 3, 4, 5
- Learning rates: 0.0001, 0.0005, 0.001, 0.005
- Epoch counts: 50, 100, 150, 200
- L1 weights: 0, 0.0001, 0.001
- L2 weights: 0, 0.0001, 0.001

This is a large experiment and can take substantial time and compute resources. The tuning results are saved to `dlinear_reg_results.json`, `lstm_reg_results.json`, and `transformer_reg_results.json`.

## Summarizing results

After the result files exist, print the top configurations and best configuration per model with:

```bash
python summary_table.py
```

Generate the performance-versus-window plot with:

```bash
python error_v_window.py
```

This creates or overwrites `error_vs_window.png`.

## Notes

- The scripts do not set random seeds, so repeated training runs may produce different results.
- The saved checkpoints are overwritten whenever a later run produces a better validation loss for the same model and window.
- The JSON files store metrics from previous runs and are not automatically regenerated by the summary or plotting scripts.
